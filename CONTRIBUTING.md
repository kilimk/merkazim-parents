# Contributing

1. Clone the repository, or fork it if you do not have write access.
2. Create a branch for your change.
3. Run `npm run dev` and edit files in `site/`.
4. Run `npm run check` and `npm run build`.
5. Check the affected pages at desktop and mobile widths, in Russian and Hebrew when relevant.
6. Open a pull request describing the change and what you checked.

Preserve approved content and source attribution. Check both right-to-left and left-to-right layouts. Never commit secrets or real form submissions.

Forms are a demonstration: they must not claim to save or send data until a real backend has been implemented. The signature counter is explicitly a demo. Chat uses local material matching.

GitHub changes do not automatically deploy the live Sites website. Coordinate publication with the project owner after review.
